How TraceWise Works

A step-by-step guide to reading and understanding code — designed for everyone, especially students who find traditional text hard to process.

1
Pick a problem

Choose a Python code snippet to trace. Start with the ⭐ beginner problem. You'll see the full code displayed clearly before you start.

2
Click "What does this code do?"

Our AI (Claude) will explain the code in plain English — no jargon. Great to read before you start tracing.

3
Select the right color for each step

Each step has a matching color on the left. Click the correct color to unlock the question for that step. Wrong color? It'll highlight the right one for you.

4
Answer the multiple-choice question

Read the question about the code and pick your answer. If you get it wrong twice, a hint appears. A personalized AI hint arrives on your second wrong attempt.

5
See your results and mastery

After finishing, you'll see a detailed breakdown and your concept mastery scores — updated after every problem you complete.

The 5 Step Colors

🟢 ScanLook at the overall structure — is this a loop, a condition, or a print statement?
🟣 ValuesRead what each variable holds — look at the right side of the = sign.
🟡 EvaluateWork out the value of an expression — like 7 % 2 or x > 3.
🔵 FollowDecide which path the code takes — the if branch or the else branch?
🔴 OutputDetermine the final output — what gets printed to the screen?
